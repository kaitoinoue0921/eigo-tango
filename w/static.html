    static

    /stˈætɪk/ やや難 頻度 9299位

    意味

    1. 静止の,固定した
    2. 動きのない,活気のない
    3. 静止電気の
    4. 静止学の
    5. 空電
    6. (空電による)ラジオの雑音,テレビの電波障害

    例文

    • House prices have remained static for several months.

      住宅の価格はここ数か月間動きがありません。

      Tatoeba #266469

    • The population of this town has been static for the last ten years.

      この町の人口はここ１０年間動きがない。

      Tatoeba #57846
