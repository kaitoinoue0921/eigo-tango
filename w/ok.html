    ok

    /ˈoʊkˈeɪ/ 最頻出 頻度 490位

    意味

    1. Oklahoma(オクラホマ州)の略
    2. {形} 大丈夫な

      • Will it really be OK with this? Will it go well?

        本当にこれで大丈夫？上手くいく？

        Tatoeba #888687

    3. 問題ない

      • It's OK to be expensive. It's an issue of feeling.

        高くてもいいのよ。気持ちの問題。

        Tatoeba #10511774

    4. 許容できる
    5. {間投} わかった

      • "Can you keep it a secret?" "OK." "I will, too."

        「秘密を守ってくれる？」「わかった」「僕も守るよ」

        Tatoeba #10568273

    6. いいよ
    7. 了解

      • You shouldn't have done that without asking Tom if is was OK.

        トムの了解も得ないで、そんなことをするのは良くないよ。

        Tatoeba #10673579

    8. {副} よく
    9. 問題なく
    10. {動} …を承認する
    11. 認可する
