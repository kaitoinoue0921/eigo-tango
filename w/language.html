    language

    /lˈæŋɡwədʒ/ 最頻出 頻度 267位

    要点言語、国語、言葉遣い

    意味

    1. 言語,言葉
    2. (一国家・一民族の持つ)国語,…語
    3. (文字・話し言葉以外の)伝達記号,人工言語;(動物の)伝達手段(鳴き声・身ぶりなど)
    4. (個人・特定のグループなどの)言葉遣い,語法,(専門の)用語,術語
    5. 語学,言語学(linguistics)

    例文

    • Language is a specifically human characteristic.

      言語は人間固有の性質である。

      Tatoeba #239738

    • The Japanese language has honorific expressions.

      日本語には敬語があります。

      Tatoeba #281647

    • I think everybody should learn another language.

      誰もが他の言語を学ぶべきだと私は思う。

      Tatoeba #3621820

    語源

    ラテン語lingua「舌」から。舌で話すもの→「言語・言葉」。

    linguistics（言語学）、bilingual（二言語を話す）も同じ仲間。
