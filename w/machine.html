    machine

    /məʃˈin/ 最頻出 頻度 968位

    要点機械、名,

    意味

    1. 機械
    2. 自動車,飛行機,自転車
    3. 加えられた力を強めたり方向を変えたりする機械(器具);てこ,滑車,くさび,斜面など
    4. 組織,(特に)派閥
    5. (自主性も意欲もない)機械のような人,機械的に働く人
    6. …を機械で作る(仕上げる);(特に)…にミシンをかける,をミシンで作る;(印刷機で)…を印刷する
    7. …をきっちり計って作る《+down+名,+名+down》

    例文

    • This vending machine won't accept 500 yen coins.

      この自動販売機に５００円硬貨は使えない。

    • Everyone was really impressed with that machine.

      みんな、その装置にとても感心した。

      Tatoeba #32199

    • The supervisor bought a really powerful machine.

      部長が、すごいハイスペック・マシン買ったそうよ。

      Tatoeba #485373

    語源

    ギリシャ語mēkhanē「仕掛け・工夫」から。うまく動くよう工夫された仕掛け→「機械」。

    mechanic（機械工）と同じ語源。

    英語の原文（Wiktionary）

    Etymology tree Proto-Indo-European *megʰ-der.? Ancient Greek μηχᾰνή (mēkhănḗ) Doric Greek μᾱχᾰνᾱ́ (mākhănā́)bor. Latin māchinabor. Middle French machinebor. English machine Borrowed from Middle French machine, from Latin māchina (“a machine, engine, contrivance, device, stratagem, trick”), from Doric Greek μᾱχᾰνᾱ́ (mākhănā́), cognate with Attic Greek μηχᾰνή (mēkhănḗ, “a machine, engine, contrivance, device”), from which comes mechanical. Displaced native Old English searu.
