    react

    /riˈækt/ 標準 頻度 3112位

    要点反応する

    意味

    1. (刺激などに)反応する《+to+名》
    2. (…に)反対する,反抗する《+against+名》
    3. (…に)影響を与える;(作用するものに)反作用する,はね返る《+on(upon)+名》
    4. (…と)化学反応を起こす《+with+名》

    例文

    • The President's decision caused the market to react.

      大統領の決定は市場に影響を与えた。

      Tatoeba #275876

    • People react to the frustration in much the same way.

      人は欲求不満に対してほとんど同じように反応する。

      Tatoeba #270138

    • Cause and effect react upon each other.

      原因と結果はお互い作用し合う。

      Tatoeba #239450
