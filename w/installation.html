    installation

    /ˌɪnstəlˈeɪʃən/ やや難 頻度 9201位

    意味

    1. (装置などの)取り付け,据え付け
    2. (人の)任命,就任
    3. (取り付けた)装置,設備
    4. 軍事施設

    例文

    • A reboot is required to complete the installation.

      インストールを完了するには再起動が必要です。

      Tatoeba #12010572

    • The installation is complete.

      インストールが完了しました。

      Tatoeba #5734998

    語源

    英語の原文（Wiktionary）

    From Middle French installation, from Medieval Latin installātiō. By surface analysis, install + -ation. Compare with Piedmontese istallassion.
